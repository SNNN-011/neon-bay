Neon Bay is an original open-world crime game that plays offline in a desktop browser: a sun-soaked coastal city to explore on foot and by car, live traffic and pedestrians, cars to steal, a wanted level with police who chase you, story missions, combat, and a HUD with a minimap. Built as plain static files with a vendored three.js, no build step and no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Keyboard and mouse: WASD move, mouse look, E enter/exit vehicles, Shift sprint, Space jump/handbrake, click shoot, Tab mission log, Esc pause.
